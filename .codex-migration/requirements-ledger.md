## 验收矩阵

- 数据层：源产品 ID、名称、分类、正文、规格、图片顺序；目标分类/产品行；R2 绝对 URL；现有 `pla-basic` 保持不变。
- 页面层：产品列表全部卡片；每个 `/products/<slug>` 详情；图库/规格/CTA；Sitemap、canonical、Product JSON-LD。
- 状态层：初始加载、图片成功/失败检查、图库或变体交互（存在时）、无规格/单图/多图/长标题状态。
- 设备层：正式域名桌面端与 390px 手机端逐产品复审。
- 发布链路：本地 SHA = GitHub `main` SHA = Vercel Production Git SHA；正式域名采用目标部署。
